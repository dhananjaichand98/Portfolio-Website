# Dhananjai Chand Portfolio

Single-page portfolio built with Next.js static export, designed for GitHub Pages hosting.

## Stack

- Next.js (App Router) with `output: "export"`
- React
- Custom CSS (colorful minimal + playful style)
- JSON-driven content for easy updates

## Local setup

```bash
npm install
npm run dev
```

Site runs at `http://localhost:3000`.

## Build static export

```bash
npm run build
```

Static files are generated in `out/`.

## Content updates (no component edits needed)

Update these files:

- `content/profile.json`: name, role, about text, socials, personality, photo
- `content/projects.json`: project cards
- `content/skills.json`: skill groups
- `content/experience.json`: timeline entries
- `content/site.json`: site metadata, nav, CTA text, Formspree endpoint

## Contact form (Formspree)

1. Create a form at [Formspree](https://formspree.io/).
2. Replace `formspreeEndpoint` in `content/site.json` with your real endpoint:

```json
"formspreeEndpoint": "https://formspree.io/f/your-real-id"
```

## Analytics (Cloudflare Web Analytics)

1. Add your site in [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/).
2. Add this environment variable in GitHub repo settings (`Settings -> Secrets and variables -> Actions`):

`NEXT_PUBLIC_CLOUDFLARE_ANALYTICS_TOKEN=<your_token>`

The script loads only if the token is present.

## SEO notes

- Metadata is in `app/layout.js`
- Sitemap is generated by `app/sitemap.js`
- Robots file is generated by `app/robots.js`
- Structured data (Person schema) is in `app/layout.js`

Update `siteUrl` in `content/site.json` to match your final GitHub Pages URL.

## GitHub Pages deployment

This repo includes a workflow at `/.github/workflows/deploy.yml`.

1. Push code to `main`.
2. In GitHub repo settings, go to `Pages`.
3. Set source to `GitHub Actions`.
4. The workflow builds and deploys `out/` automatically.
